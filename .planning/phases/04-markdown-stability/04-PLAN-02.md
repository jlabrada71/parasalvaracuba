<task name="Task 2: Update Vote Endpoints to Use ON CONFLICT Upsert Pattern">

**What it does:**
Modify POST `/api/ideas/[id]/votes` endpoint to use PostgreSQL ON CONFLICT DO UPDATE (upsert) pattern instead of application-level check-then-insert. Same for POST `/api/comments/[commentId]/votes`. This makes vote updates atomic at the database level, eliminating the race condition window.

**Why it matters:**
The current application checks "does vote exist?" then inserts a new one. With concurrent requests, both can pass the check and insert duplicates. ON CONFLICT DO UPDATE makes this atomic: the database either inserts or updates in a single operation. This is STAB-01 (fix vote race condition).

**Acceptance criteria:**
- [ ] `server/api/ideas/[id]/votes.post.ts` uses `INSERT ... ON CONFLICT (idea_id, email) DO UPDATE SET vote_value = EXCLUDED.vote_value`
- [ ] `server/api/comments/[commentId]/votes.post.ts` uses `INSERT ... ON CONFLICT (comment_id, email) DO UPDATE SET vote_value = EXCLUDED.vote_value`
- [ ] Both endpoints accept {vote_value: 1 | -1 | 0} in request body
- [ ] Both endpoints return {id, entity_id, email, vote_value, created_at, updated_at}
- [ ] Endpoint handles missing entity gracefully (returns 404 if idea/comment not found)
- [ ] Error responses include descriptive messages (no raw DB errors)

**Key files touched:**
- `server/api/ideas/[id]/votes.post.ts`
- `server/api/comments/[commentId]/votes.post.ts`

**Complexity:** Medium
**Estimate:** 2 hours

**Implementation:**

For `server/api/ideas/[id]/votes.post.ts`:

```typescript
import { defineEventHandler, readBody } from 'h3'
import { query } from '~/server/database'

export default defineEventHandler(async (event) => {
  const { id } = event.context.params
  const { vote_value } = await readBody(event)

  // Validate idea exists
  const idea = await query(
    'SELECT id FROM ideas WHERE id = $1',
    [id]
  )
  if (idea.rows.length === 0) {
    throw createError({ statusCode: 404, statusMessage: 'Idea not found' })
  }

  // Get email from context (set by auth middleware)
  const email = event.context.email
  if (!email) {
    throw createError({ statusCode: 401, statusMessage: 'Unauthorized' })
  }

  // Upsert vote: INSERT with ON CONFLICT DO UPDATE
  const result = await query(
    `INSERT INTO votes (idea_id, email, vote_value)
     VALUES ($1, $2, $3)
     ON CONFLICT (idea_id, email)
     DO UPDATE SET vote_value = EXCLUDED.vote_value, updated_at = NOW()
     RETURNING id, idea_id, email, vote_value, created_at, updated_at`,
    [id, email, vote_value]
  )

  return result.rows[0]
})
```

For `server/api/comments/[commentId]/votes.post.ts`:

```typescript
import { defineEventHandler, readBody } from 'h3'
import { query } from '~/server/database'

export default defineEventHandler(async (event) => {
  const { commentId } = event.context.params
  const { vote_value } = await readBody(event)

  // Validate comment exists
  const comment = await query(
    'SELECT id FROM comments WHERE id = $1',
    [commentId]
  )
  if (comment.rows.length === 0) {
    throw createError({ statusCode: 404, statusMessage: 'Comment not found' })
  }

  // Get email from context
  const email = event.context.email
  if (!email) {
    throw createError({ statusCode: 401, statusMessage: 'Unauthorized' })
  }

  // Upsert vote
  const result = await query(
    `INSERT INTO votes (comment_id, email, vote_value)
     VALUES ($1, $2, $3)
     ON CONFLICT (comment_id, email)
     DO UPDATE SET vote_value = EXCLUDED.vote_value, updated_at = NOW()
     RETURNING id, comment_id, email, vote_value, created_at, updated_at`,
    [commentId, email, vote_value]
  )

  return result.rows[0]
})
```

Create `server/api/ideas/[id]/comments/[commentId].delete.ts`:

```typescript
import { defineEventHandler } from 'h3'
import { query } from '~/server/database'

export default defineEventHandler(async (event) => {
  const { id: ideaId, commentId } = event.context.params

  // Get email from context (set by auth middleware)
  const email = event.context.email
  if (!email) {
    throw createError({ statusCode: 401, statusMessage: 'Unauthorized' })
  }

  // Verify comment exists and belongs to the idea
  const comment = await query(
    'SELECT id, email FROM comments WHERE id = $1 AND idea_id = $2',
    [commentId, ideaId]
  )
  if (comment.rows.length === 0) {
    throw createError({ statusCode: 404, statusMessage: 'Comment not found' })
  }

  // Verify user is comment author (or admin - for now, just author)
  const commentData = comment.rows[0]
  if (commentData.email !== email) {
    throw createError({ statusCode: 403, statusMessage: 'Forbidden: not comment author' })
  }

  // Delete comment (CASCADE will delete nested replies and votes)
  await query(
    'DELETE FROM comments WHERE id = $1',
    [commentId]
  )

  // Verify deletion by checking votes are gone
  // (This is implicit if CASCADE is working, but good for logging/verification)

  return { success: true, message: 'Comment deleted' }
})
```
