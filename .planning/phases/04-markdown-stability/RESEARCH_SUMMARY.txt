KEY FINDINGS
============

1. MARKDOWN EDITOR INTEGRATION
   - Use Tiptap 3 (@tiptap/vue-3 @3.20.5) with Vue 3 Composition API
   - Component: MarkdownEditor.vue with toolbar and optional preview
   - SSR requirement: CRITICAL - must use immediatelyRender: false
   - Database: Store raw Markdown, no schema changes needed
   - Integration: Create.vue, [id].vue, CommentThread.vue, CommentItem.vue

2. SECURITY-FIRST XSS PREVENTION
   - Pattern: marked.js (parse Markdown) → DOMPurify (sanitize HTML) → render
   - Component: MarkdownRenderer.vue with safe allowlist of tags/attributes
   - DOMPurify 3.0 configuration restricts to: p, strong, em, a, img, h1-h6, lists, code, blockquote
   - Backward compatible: plain text renders fine (no migration needed)
   - Testing: 20+ OWASP payloads covering script tags, event handlers, data URIs, encoding bypasses

3. VOTE RACE CONDITION FIX
   - Root cause: Application-level check-then-insert has race condition window
   - Solution: PostgreSQL ON CONFLICT DO UPDATE (upsert) for atomic operation
   - Migration needed: 004_vote_race_fix.sql adds UNIQUE constraints with partial indexes
   - Files affected: server/api/ideas/[id]/votes.post.ts and server/api/comments/[commentId]/votes.post.ts
   - Data cleanup: Query for duplicates, keep latest vote if found

4. COMMENT DELETION EDGE CASES
   - Current schema already has CASCADE on comments.parent_comment_id and votes.comment_id
   - Edge cases handled: Delete comment → deletes nested replies → deletes votes on all
   - Missing: DELETE endpoint for comments
   - New file: server/api/ideas/[id]/comments/[commentId].delete.ts

5. COMPONENT ARCHITECTURE
   - MarkdownEditor: Rich editor with toolbar, split/tab preview, character count
   - MarkdownRenderer: Safe display component with Markdown parsing and DOMPurify sanitization
   - Props/events clearly defined for integration into existing forms
   - No API changes required - components send/receive Markdown strings

6. TESTING STRATEGY
   - Unit tests: MarkdownEditor (toolbar, preview, input), MarkdownRenderer (rendering, sanitization)
   - Security tests: 20+ XSS payloads covering all OWASP attack vectors
   - Integration tests: Concurrent vote prevention, comment cascade deletion, workflow regression
   - All test files specified with content examples
