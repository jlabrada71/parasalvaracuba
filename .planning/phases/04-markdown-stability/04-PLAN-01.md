## Objective

Build the security foundation for Markdown support by creating the MarkdownRenderer component with XSS protection, the MarkdownEditor component with Tiptap 3, and comprehensive security tests. Also prepare the database migration for vote deduplication to fix the race condition.

**Purpose:** Phase 4 requires security-first Markdown support. Plan 01 establishes the secure rendering layer (MarkdownRenderer + DOMPurify), the rich editor layer (MarkdownEditor + Tiptap), and the database constraints needed to prevent concurrent vote duplicates.

**Output:** Tested components ready for integration into Create Idea form, Idea detail page, and Comment forms. Database migration ready to apply.

<task name="Task 1: Create Database Migration for Vote Deduplication">

**What it does:**
Create the PostgreSQL migration (004_vote_race_fix.sql) that adds UNIQUE constraints with partial indexes to prevent concurrent vote duplicates. This migration adds constraints to both `votes.idea_id` and `votes.comment_id` to enforce one vote per email per entity.

**Why it matters:**
The current application-level check-then-insert has a race condition window where concurrent requests can both pass the check and insert duplicate votes. PostgreSQL ON CONFLICT with UNIQUE constraints makes this atomic at the database level. This is a critical stability fix (STAB-01).

**Acceptance criteria:**
- [ ] Migration file exists at `db/migrations/004_vote_race_fix.sql`
- [ ] Migration can be applied without errors (`psql "$DATABASE_URL" -f db/migrations/004_vote_race_fix.sql`)
- [ ] UNIQUE constraints exist for (idea_id, email) and (comment_id, email) with IS NOT NULL filters
- [ ] Partial indexes created for idea_id IS NOT NULL and comment_id IS NOT NULL
- [ ] Existing votes on ideas are preserved
- [ ] Inserting duplicate vote on idea fails with UNIQUE constraint violation
- [ ] Inserting duplicate vote on comment fails with UNIQUE constraint violation

**Key files touched:**
- `db/migrations/004_vote_race_fix.sql`

**Complexity:** Medium
**Estimate:** 1 hour

**Implementation:**

Create `db/migrations/004_vote_race_fix.sql` with the following structure:

```sql
-- Migration: 004_vote_race_fix.sql
-- Objective: Add UNIQUE constraints to prevent concurrent vote duplicates

BEGIN;

-- Add UNIQUE constraint for idea votes (only for rows where idea_id IS NOT NULL)
-- Partial index allows multiple null comment_id rows for each idea
ALTER TABLE votes
ADD CONSTRAINT votes_idea_unique UNIQUE (idea_id, email)
WHERE idea_id IS NOT NULL;

-- Add UNIQUE constraint for comment votes (only for rows where comment_id IS NOT NULL)
-- Partial index allows multiple null idea_id rows for each comment
ALTER TABLE votes
ADD CONSTRAINT votes_comment_unique UNIQUE (comment_id, email)
WHERE comment_id IS NOT NULL;

-- Partial indexes for performance (queries that filter on idea_id or comment_id)
CREATE INDEX idx_votes_idea_id_not_null ON votes(idea_id, email)
WHERE idea_id IS NOT NULL;

CREATE INDEX idx_votes_comment_id_not_null ON votes(comment_id, email)
WHERE comment_id IS NOT NULL;

COMMIT;
```

  <div class="markdown-output" v-html="sanitizedHtml"></div>

<script setup lang="ts">
import { computed } from 'vue'
import { marked } from 'marked'
import DOMPurify from 'dompurify'

const props = defineProps<{
  markdown: string
  maxPreviewLength?: number
}>()

const sanitizedHtml = computed(() => {
  if (!props.markdown || typeof props.markdown !== 'string') {
    return ''
  }

  // Truncate for preview if maxPreviewLength is set
  const content = props.maxPreviewLength
    ? props.markdown.slice(0, props.maxPreviewLength)
    : props.markdown

  // Step 1: Parse Markdown to HTML
  let html = ''
  try {
    html = marked(content)
  } catch (e) {
    console.warn('Markdown parse error:', e)
    return DOMPurify.sanitize(content)
  }

  // Step 2: Sanitize with DOMPurify
  return DOMPurify.sanitize(html, {
    ALLOWED_TAGS: [
      'p', 'br', 'strong', 'b', 'em', 'i', 'u', 'a', 'img',
      'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
      'ul', 'ol', 'li', 'blockquote', 'code', 'pre',
      'table', 'thead', 'tbody', 'tr', 'td', 'th'
    ],
    ALLOWED_ATTR: ['href', 'title', 'alt', 'src', 'class'],
    KEEP_CONTENT: true,  // Keep text if tag is removed
  })
})
</script>

<script setup lang="ts">

import StarterKit from '@tiptap/starter-kit'

import MarkdownRenderer from './MarkdownRenderer.vue'

const props = defineProps<{
  modelValue: string
  placeholder?: string
  maxLength?: number
  previewDefault?: 'split' | 'tab' | 'none'
}>()

  'update:modelValue': [value: string]
  'input': [value: string]
  'save': [value: string]

  content: props.modelValue,

    emit('input', markdown)
