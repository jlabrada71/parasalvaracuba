RESPONSIVE BREAKPOINT CHANGES
================================================================================

AT 1199px → 1200px (Desktop → Tablet):
- Grid: 3 columns → 2 columns
- Hero margins: 8.5rem/5.5rem → 4rem/3rem
- Font sizes: maintain (or 95%)

AT 767px → 768px (Tablet → Mobile):
- Grid: 2 columns → 1 column
- Hero margins: 4rem/3rem → 1rem padding
- Filter chips: Single line → Horizontal scroll
- Pagination: Numbers → Dots or "Load More"
- Header: Nav visible → Hamburger menu (optional)
- Font sizes: 90-95% of desktop
